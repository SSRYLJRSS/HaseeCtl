# HaseeCtl 使用说明

神舟（蓝天 Clevo）Control Center 的替代品。专注五件事：**风扇曲线（可存多套、开机/唤醒自动恢复）**、**性能模式**、**充电上限**、**显卡切换**、**键盘灯**，并接管 Fn 热键。

- 安装位置：`%LOCALAPPDATA%\Programs\HaseeCtl`（约 32 MB，无需管理员）
- 配置：`%APPDATA%\HaseeCtl\settings.json`
- 日志：`%LOCALAPPDATA%\HaseeCtl\logs\haseectl-YYYYMMDD.log`
- 依赖：.NET 10 桌面运行时（本机已具备）

## 一、安装

双击 `dist\HaseeCtl\安装.cmd`（或运行 `install.ps1`）。它会：

1. 结束旧实例并把程序复制到 `%LOCALAPPDATA%\Programs\HaseeCtl`
2. 创建桌面与开始菜单快捷方式（「HaseeCtl 控制中心」）
3. 放入启动文件夹，登录后自动运行后台服务（托盘图标）
4. 登记到「设置 → 应用」的卸载列表
5. 启动后台服务（Agent）

参数：`install.ps1 -InstallDir D:\HaseeCtl`、`-NoAutostart`、`-NoShortcuts`。

## 二、卸载

双击安装目录里的 `卸载.cmd`，或「设置 → 应用 → HaseeCtl 控制中心 → 卸载」。

默认**保留**配置；要连配置一起删，卸载后手动删 `%APPDATA%\HaseeCtl`。

## 三、界面

| 页面 | 内容 |
| --- | --- |
| 概览 | CPU/GPU 温度与转速实时值、当前性能模式/风扇模式/充电上限/显卡模式、快捷操作（全速 3 秒、恢复自动、切换性能模式、重新应用） |
| 风扇控制 | 多套方案下拉、CPU/GPU 曲线编辑、应用曲线、恢复出厂、运行模式（自动/静音/最大/全速 3 秒） |
| 性能模式 | 省电/安静/性能/娱乐、强冷、开机自动应用 |
| 电池充电 | 电量显示、充电上限开关、起止阈值（取固件选项）、70%/80% 预设 |
| 显卡 | 独显直连 / 混合模式（切换后需重启） |
| 键盘灯 | 开关、亮度 0–9、灯效、17 色预设、左中右/全部三区颜色 |
| 设置与关于 | 行为开关、文件路径、重载、重新应用、硬件能力自检、版本 |

### 风扇曲线怎么改

- **直接用鼠标拖曲线上的圆点**，不用输入数字：横向拖改温度、纵向拖改转速，右下角的实时数值会跟着变。
- 四个节点：起转（T1/D1）、节点 2、节点 3、满载（T4/D4）。只有节点 2、3 可拖动；起转与满载由固件固定（显示为空心的灰点）。
- 图上的虚线是当前实测温度，方便对照曲线是否够用。
- CPU / GPU 两套曲线用顶部药丸按钮切换；「GPU 抄 CPU」可一键复制。
- 改完点「保存修改」写入配置文件，点「应用曲线」写入 EC 并切到自定义模式；「只推送」只写曲线不切模式。
- 三套预设：安静 / 均衡 / 性能，可「另存为…」建自己的方案。
- **开机与睡眠唤醒后会自动重新下发**当前方案 —— 原版记不住自定义配置的问题就在这。

## 四、热键

| 键码 | 功能 |
| --- | --- |
| 89 | 循环切换性能模式 |
| 112 | 风扇静音 / 自动 |
| 143 | 风扇最大 |
| 149 | 打开控制中心 |
| 129 / 130（32/33） | 键盘灯亮度 − / + |
| 158 / 159 | 键盘灯开 / 关 |
| 246 / 247 | 摄像头开 / 关 |
| 133 / 134 | 飞行模式 |
| 93 | 触控板开关（读系统状态并提示） |
| 199–204 | 数字键/大写/滚动锁定提示 |
| 250 / 251 | 音量 |

热键来源**自动判断**，两条通道：

- 原厂服务 `CCDCHUService` 在运行 → 订阅它的 OutLog 日志（当前情况，日志写「热键来源: 服务日志 OutLog」）
- 该服务不存在（**卸载官方 Control Center 之后**）→ 直接向 ACPI 驱动注册等待事件（日志写「热键来源: ACPI 驱动通知」）

两条通道都已实测注册成功。可用环境变量 `HASEECTL_FORCE_DRIVER_HOTKEYS=1` 强制走驱动通道验证。

## 五、稳定性设计

- 后台 Agent 常驻托盘，单实例锁，重复启动直接退出。
- 开机、睡眠唤醒（`PBT_APMRESUME_AUTOMATIC`）后重新下发风扇与性能模式；唤醒后 1.5 秒与 4 秒各补一次。
- 配置文件被改动后 400ms 去抖自动重载，界面改完立刻生效，无需重启 Agent。
- 配置损坏或读取失败 → 回退默认值并重建，不会崩溃。
- 数据目录可写性探测：`%APPDATA%` 不可写时依次退到 `%LOCALAPPDATA%`、`%TEMP%`、程序目录；可用 `HASEECTL_DATA_DIR` 强制指定。
- 每一步硬件操作都写日志，出问题先看日志。

## 六、卸载官方 Control Center 之后

可以直接卸载，本工具不依赖它。只有两点差异：

1. 热键改走驱动通道，功能不变。
2. 官方特有的少数附加功能（OLED 关屏键 215、部分系统级联动）不再提供——这些原本由官方服务实现，不在本工具范围。

## 七、排障

| 现象 | 处理 |
| --- | --- |
| 托盘没有图标 | 看日志有无「HaseeCtl Agent 启动」；手动运行安装目录的 `HaseeCtl.Agent.exe` 看报错 |
| 显示「未连接硬件」 | 设备管理器确认 `ACPI\CLV0001` 状态正常，然后重启后台服务 |
| 热键没反应 | 看日志的「热键来源」；官方服务在跑却无响应时，用 `HASEECTL_FORCE_DRIVER_HOTKEYS=1` 试驱动通道 |
| 改完风扇没变化 | 确认模式不是「自动」；「应用曲线」后看日志有无「应用风扇: mode=custom」 |
| 想恢复出厂配置 | 删 `%APPDATA%\HaseeCtl\settings.json` 后点「重新应用」 |
